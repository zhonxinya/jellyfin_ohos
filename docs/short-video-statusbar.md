# 短视频页顶部避让系统空间（恢复状态栏）

## 现象与口径

用户："短视频顶部避免侵占系统空间"。

修复前「视频」页签是全沉浸（隐藏状态栏 + 铺满整屏），页面内容从屏幕 y=0 起，
顶部浮层工具行（「短视频」标题、计数、清晰度标签、三个按钮）整个压在系统状态栏区域里。
模拟器实测：系统状态栏窗口 rect = `[0,0,1260,131]`（顶部 131px = 38.8vp），
而工具行修复前在 y=33..150px。

修复方式（用户确认选 B）：**「视频」页签恢复显示系统状态栏，画面与控件都从状态栏下方开始**。

## 实现

`common/WindowFullscreen.ets`：

- 新增 `enterWithStatusBar(win)`：`setWindowSystemBarEnable(['status'])` + `setWindowLayoutFullScreen(true)`
  —— 只留状态栏，导航栏仍隐藏（底部页签行才不会被系统栏顶上来，PR #54/#56 结论不受影响）；
- 新增 `statusBarTopVp(win)`：读 `TYPE_SYSTEM` 避让区的高度（vp），供"挖孔是否比状态栏更深"的差额计算。

`pages/MainShell.ets`：

- `applyChromeForTab`：「视频」页签走 `enterWithStatusBar`，其余页签仍走全沉浸 `enter`；
- 新增 `refreshTopInset(win, statusBarKept)`：避让值必须在系统栏状态**切换完成之后**再算。
  两个值用途不同、**不能混**：
  - `cutout`（挖孔）→ 写进 `AppStorage`，给压栈页面（详情/播放/设置…）与外壳顶栏用；
  - `statusBarVp`（**整条**系统状态栏）→ 给「视频」页的工具行浮层用。
- 说明：`setWindowLayoutFullScreen(true)` + 保留状态栏这一档**只能用于不画外壳顶栏的「视频」页签**
  ——实测该模式会把外壳顶栏压扁（190px→59px），因此「媒体库」「设置」仍走全沉浸。

> **修正记录（第二轮实测）**：「视频」页的避让量一开始写成 `statusBarKept ? max(0, 挖孔 - 状态栏) : 挖孔`
> —— 也就是"挖孔比状态栏更深时才补差额"。**这个减法在本窗口是错的**：
> 本窗口 `setWindowLayoutFullScreen(true)`，页面从 **y=0 全屏绘制**，
> `dumpLayout` 报的 root `y=132` 只是系统的**内容框元数据，不是绘制原点**。
> 当挖孔高度 ≈ 状态栏高度（模拟器 39vp vs 39vp）时，`max(0, 39-39)` = **0**，
> 等于把本该补的整条状态栏又扣掉了 —— 工具行的 `padding.top=10vp` 直接落在 y≈40，
> 仍然压在状态栏里。现改为**直接避让整条状态栏高度**（挖孔就在状态栏那一条内，无需再叠加）。

## 验证（模拟器 1260×2844，density 3.375，验收脚本 `_sv-top-verify.py` + 探针 v2）

| 判定 | 修复前 | 修复后 |
| --- | --- | --- |
| 页面内容起始 y | 0px（工具行 y=33..150 压进状态栏区） | **132px**（状态栏之下） |
| 顶部 0..131px 归属 | 视频画面 | 系统状态栏（图标可见：左右亮像素团） |
| 底部页签行 | 2655..2844 | 2655..2844（仍贴屏幕最底边） |
| 「媒体库」页签 | 全沉浸 | 全沉浸（顶栏 y=55，无回归） |

注意：验收脚本里"文本节点 vs 容器边界"这类判定要以**容器 bounds**为准
（页签文字节点只是 56vp 行内的一小块，不代表行底；页面大容器从 y=132 起即内容已整体下移）。

### 第二轮实测（修正避让算法后，`uitest dumpLayout` 取节点边界）

`hidumper -s WindowManagerService -a '-a' | grep SCBStatusBar` → 状态栏 rect `[0,0,1260,131]`。

| 项 | 值 |
| --- | --- |
| 状态栏区域（y<131）内的**应用**节点 | **无**（该区间只有系统的时钟 `08`/`:`/`01` 与电量 `100`） |
| 应用顶部菜单首行「短视频」 | `y = 165..228` |
| 页码 `1/5`、清晰度徽标 `自动 · 转码` | `y = 169..225` |
| 「来自：欧美剧」 | `y = 235..282` |

即应用内容整体从 **y=165** 起，与状态栏（0..131）之间留 34px 间隔 —— **零重叠**。

判定方法说明：本页画面是暗色影像，**按像素亮度找"最上一条亮内容"不可靠**
（实测采样判不出 UI）；改用 `dumpLayout` 的节点边界，
能明确区分"系统节点"（时钟/电量，由系统窗口提供）与"应用节点"，结论更硬。
